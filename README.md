# Introduction to Programming — Practicals 1–12

- Each `Practical_XX.py` file contains the practical examples first and the **Practice Questions from the supplied worksheets/manual** after them.
- Every question starts with a short comment such as `# Q1. ...`; the code for that question comes directly underneath.
- The files use beginner-friendly Python and avoid menu systems or `exec()` wrappers.
- Practicals 6 and the array section of Practical 7 require NumPy (`pip install numpy`).
- Run a file from a terminal with `python Practical_01.py` (change the filename as needed). These are lab-note style files; if you only need to execute one question, select/run that question's code block.

Files:
- `Practical_01.py` through `Practical_12.py`
